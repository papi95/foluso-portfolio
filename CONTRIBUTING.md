# Contributing

Thanks for helping improve the portfolio.

## Workflow

1. Keep changes focused and preserve the dependency-free static-site approach unless a change has a clear need.
2. Use semantic HTML and native controls; verify keyboard behavior and mobile layout.
3. Respect `prefers-reduced-motion` and ensure content remains available without JavaScript enhancements.
4. Run the Rust test suite after changing Rust code: `cd rust-core && cargo test`.
5. Review the page at desktop and mobile widths, and check browser console errors before submitting.

## Content and assets

Use only authorized images, fonts, and copy. Optimize any added assets, provide text alternatives for meaningful images, and update the docs when behavior or setup changes.
